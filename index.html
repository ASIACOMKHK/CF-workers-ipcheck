NetSight Pro 是一款部署在 Cloudflare Workers 上的开源全功能网络诊断工具，提供实时延迟监控、带宽测速、CPU 性能、WebSocket 延迟、TTFB 分析、WebRTC 泄漏检测等 20+ 项诊断能力。 NetSight Pro is an open-source, full-featured network diagnostic tool on Cloudflare Workers — 20+ capabilities including live latency, bandwidth, CPU, WebSocket, TTFB and WebRTC leak checks.

⚡ 特性一览Features

一站式网络诊断，覆盖从链路质量到安全协议的全方位检测。One-stop diagnostics — from link quality to security protocols.

实时 RTT 监控Live RTT

每 2 秒发送 HEAD 探测，绘制延迟趋势图，计算抖动与丢包率，自动评估连接质量。2-second HEAD probes charting latency, jitter and packet loss.

带宽测速Speed Test

多档位下载与上传测试，计算平均速度，直观反映网络吞吐能力。Multi-tier download & upload tests with average throughput.

CPU 基准测试CPU Benchmark

执行密集型数学运算，评估 Worker 或客户端设备的计算性能。Compute-bound benchmark for the Worker or the client device.

WebSocket 延迟WebSocket

建立双向 WebSocket 连接进行 ping/pong 测距，反映实时双向通信延迟。Bidirectional ping/pong round-trip over a live WebSocket.

并发下载测试Concurrency

模拟多路并发请求，检测网络在多连接场景下的吞吐表现。Simulates parallel requests to probe multi-connection throughput.

流式传输吞吐量Streaming

流式读取大文件（最大 10MB），测试长连接下的稳定传输速率。Streams large files (up to 10MB) to measure sustained transfer rate.

TTFB 分阶段分析TTFB Breakdown

分解 DNS、TCP、TLS、等待、下载各阶段耗时，精确定位性能瓶颈。Splits DNS, TCP, TLS, wait and download to pinpoint bottlenecks.

安全与协议检测Security & Protocol

显示 TLS 版本、加密套件、HTTP/2/3 支持、ECH 状态、JA3/JA4 指纹、机器人评分。TLS version, cipher suites, HTTP/2/3, ECH, JA3/JA4 fingerprints and bot score.

双栈 IP 与地理位置Dual-Stack Geo

同时获取 IPv4 与 IPv6，通过 ipapi.co 获取真实地理位置及到边缘节点的距离。Fetches IPv4 & IPv6 and resolves real geolocation and edge distance via ipapi.co.

IP 风险评分IP Risk Score

集成 ip-api.com，检测 IP 是否为代理 / 托管 / 移动网络，并给出派生风险等级。Uses ip-api.com to flag proxy / hosting / mobile IPs with a derived risk level.

WebRTC 泄漏检测WebRTC Leak

检测本地和公网 IP 是否通过 WebRTC 泄露，保护隐私安全。Detects local & public IP exposure via WebRTC to protect privacy.

流媒体连通性Streaming Access

检测 Netflix、Disney+、YouTube、ChatGPT 等服务的可达性。Checks reachability of Netflix, Disney+, YouTube and ChatGPT.

多节点对比Multi-Node

输入其他 Worker 节点 URL，并行测试延迟，生成直观对比表格。Enter other Worker node URLs and compare latency in a side-by-side table.

测速历史与用量统计History & Usage

存储最近测速记录，展示 API 端点调用统计（需 KV 支持）。Stores recent speed results and API usage stats (requires KV).

一键生成诊断报告Report Export

复制纯文本报告，包含所有关键指标，便于分享和存档。Copy a plain-text report of all key metrics for sharing or archiving.

多语言与主题i18n & Theme

支持 English、简体中文、繁體中文，深色/浅色/跟随系统主题，自动适配。English, 简体中文, 繁體中文 — dark / light / system theme, auto-adaptive.

🚀 快速部署Quick Start

3 分钟即可拥有自己的网络诊断服务。Spin up your own diagnostic service in about 3 minutes.

1

克隆仓库Clone

git clone https://github.com/BlueDriftHK/CF-workers-netdiag.git

2

安装 WranglerInstall

npm install -g wrangler

3

配置 KV（可选）KV (optional)

wrangler kv namespace create "SPEED_HISTORY"

4

发布Deploy

wrangler deploy
